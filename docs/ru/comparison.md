# Сравнение с другими инструментами

[← README](../../README.ru.md) · [English](../comparison.md)

Другие инструменты в этой нише и чем они отличаются (по их README, август 2026):

| | **claude-acc** | [cswap](https://github.com/realiti4/claude-swap) | [aisw](https://github.com/burakdede/aisw) | direnv + `CLAUDE_CONFIG_DIR` |
|---|---|---|---|---|
| Модель | аккаунт — свойство директории | один глобально активный логин (+ опциональная карта директория → аккаунт) | один глобально активный профиль на инструмент | аккаунт — свойство директории |
| Обычный `claude` выбирает аккаунт по cwd | да, по `cd` | через `cswap run` в замапленной директории | нет — `aisw workspace guard` предупреждает/блокирует при несовпадении | да, там где есть `.envrc` |
| Наследование по дереву и переопределения | да | да (ближайший замапленный предок) | привязка по репозиторию / git-remote | `.envrc` на директорию |
| Разные аккаунты в параллельных терминалах | да | да (session mode) | нет — переключение глобальное | да |
| Свои `settings.json`, `CLAUDE.md`, агенты, скиллы, MCP на аккаунт | да — отдельная config-папка | нет — сессии используют общий `~/.claude`, отдельная только история | частично — изолированный home там, где инструмент это поддерживает | да |
| Живой аудит личности за config-папкой | `doctor` — OAuth profile API: email, план, UUID | email'ы аккаунтов из сохранённых кредов | `doctor` / `verify` проверяют целостность конфига | нет |
| Расход лимитов | `usage` — 5ч / 7д по каждому аккаунту | TUI-дашборд, меню-бар macOS, адаптивный опрос | нет | нет |
| Автоматическая ротация при упоре в лимит | нет (вне задачи) | да — стратегии, cooldown, гистерезис | нет | нет |
| Статус-панель с активным аккаунтом | `statusline --install` | нет | нет | нет |
| Запуск из IDE (JetBrains, терминал VS Code) | враппер в `PATH` + симлинк `ide/` | следует глобальному логину | следует глобальному профилю | нет |
| **Нативный UI** VS Code (собственная панель расширения) | `vscode install` — `claudeCode.claudeProcessWrapper` | нет | нет | нет |
| Аккаунты в **десктопном приложении** Claude | `desktop` — изолированные профили, работают одновременно | нет | нет | нет |
| Подхватить существующую config-папку без повторного логина | `import` — перевешивает запись в Keychain на новый путь | `add` / `import` экспортов кредов | сохранить текущий логин как профиль | n/a |
| Другие coding CLI (Codex, Gemini) | нет | нет | да | n/a |
| Рантайм | Rust-бинарник (или один zsh-скрипт) | Python (uv / pipx) | Rust | direnv |

Коротко: **cswap** — если нужен один активный аккаунт и автоматическая ротация вокруг лимитов; **aisw** — если вы жонглируете несколькими coding CLI; рецепт с **direnv** — если direnv уже стоит и ничего лишнего ставить не хочется. `claude-acc` — про то, чтобы аккаунты были *разделены* (work / personal / client), привязка жила в дереве директорий, и было видно, какая личность реально стоит за каждой config-папкой.
