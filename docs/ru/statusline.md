# Статус-панель

[← README](../../README.ru.md) · [English](../statusline.md)

Claude Code умеет показывать настраиваемую панель внизу экрана. `claude-acc statusline` рисует её так, что **первым идёт аккаунт, под которым запущена сессия** — то, чего сам Claude Code показать не может — затем git-ветка, модель, проект и индикатор контекстного окна:

```
work │ ⎇ main │ Opus 4.8 (1M context) │ approvalmax-product-AM-37583 │ ▓▓▓░░░░░░░ 32%
```

Установить в `settings.json` активного аккаунта одной командой:

```bash
claude-acc statusline --install
```

Потом перезапустите Claude Code. Команда читает session-JSON Claude Code со stdin — данные бесплатные, без запросов к API. Имя аккаунта берётся из `CLAUDE_CONFIG_DIR`. Цвета уважают `NO_COLOR`.

### Что показывает индикатор и чем он не является

Это **контекстное окно текущей сессии**, из `context_window.remaining_percentage`, с цветом зелёный → жёлтый → красный и черепом, когда автокомпакт уже близко. В начале сессии, пока Claude Code не заполнил этот блок, индикатор не показывается.

Это **не** лимит вашей подписки. Он — отдельное число, и показывает его [`claude-acc usage`](identity.md#сколько-лимита-осталось-usage): окна 5 часов и 7 дней. Совпадать эти две цифры не будут никогда, потому что меряют разное: одна — насколько заполнен текущий разговор, другая — сколько израсходовано от плана. Именно о такой путанице была [#140](https://github.com/Nemo-Illusionist/claude-code-account-switcher/issues/140), и причиной были эти же страницы — они ещё долго описывали 5-часовое чтение после того, как индикатор перестал его показывать.

Процент к тому же считается от **полезного** окна, а не от сырого. Claude Code резервирует часть под автокомпакт — по умолчанию ~16.5% или столько токенов, сколько указано в `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, — поэтому сырые «свободно 84%» на деле означают, что индикатор уже полон. Нормировка делает так, что 80% значит «компакт близко», а не «ещё есть запас»; по этой же причине наше число отличается от того, что показывает сам Claude Code.

Хотите прописать вручную? Укажите в `statusLine` установленный бинарник:

```json
{
  "statusLine": { "type": "command", "command": "~/.claude-switch/bin/claude-acc statusline" }
}
```

> Статус-панель — фича Rust CLI: `statusLine` в Claude Code запускает путь к бинарнику/скрипту, а shell-дистрибуция не может дать его как sourced-функцию.
